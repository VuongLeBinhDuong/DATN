This appendix outlines the steps required to deploy the system locally using Docker and Python.

\section*{1. Prerequisites}
To successfully deploy this system, several dependencies must be met: (i) Docker and Docker Compose must be installed for the database, (ii) Python 3.10 or higher is required for the backend services, and (iii) Ollama must be installed locally for LLM inference.

\section*{2. Infrastructure Setup (Neo4j)}
Start the Neo4j database using Docker Compose:
\begin{lstlisting}[language=bash, breaklines=true]
docker-compose up -d
\end{lstlisting}

\section*{3. Install Python Dependencies}
Navigate to the root directory and install dependencies:
\begin{lstlisting}[language=bash, breaklines=true]
pip install -r requirements.txt
\end{lstlisting}

\section*{4. Start Ollama and Pull Models}
Ensure Ollama is running and pull the necessary models:
\begin{lstlisting}[language=bash, breaklines=true]
ollama serve
ollama pull llama3.2:3b
ollama pull qwen2.5:1.5b
\end{lstlisting}

\section*{5. Start the FastAPI Backend}
\begin{lstlisting}[language=bash, breaklines=true]
uvicorn main:app --host 0.0.0.0 --port 8000 --reload
\end{lstlisting}

\section*{6. Start Knowledge Graph Extraction}
To incrementally extract and ingest entities into Neo4j:
\begin{lstlisting}[language=bash, breaklines=true]
python scripts/kg_extract_entities.py --only-missing --limit 1000
\end{lstlisting}
